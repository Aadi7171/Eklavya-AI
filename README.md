# 🏹 Eklavya-AI

> **Empowering Rural Bharat with AI-Driven Career Growth and Blockchain-Verified Skills.**

Eklavya-AI is a next-generation educational and career empowerment platform designed for rural Indian communities — combining Voice-AI onboarding, Agentic Salary Negotiation, and Blockchain-Verified Credentials to bridge local talent with global opportunities.

## 🎯 The Problem

Rural India has millions of skilled workers — tractor mechanics, irrigation managers, craftspeople — whose expertise is invisible to the formal job market because they lack verifiable credentials and negotiation tools. Eklavya-AI fixes that.

---

## 🌟 Key Features

### 🎙️ Voice-Powered Onboarding
Users describe their skills in **Hindi and regional languages** via voice. The AI extracts relevant skills and automatically builds a professional profile — no forms, no typing barriers.

### 👔 Agentic Negotiator
An AI-driven negotiator helps users advocate for fair salary and employment terms by surfacing their verified Poly-badges during hiring conversations.

### ⛓️ Blockchain-Verified Credentials (Poly-badges)
Skill credentials are issued as **NFT-based Poly-badges on the Polygon blockchain** — tamper-proof, portable, and globally verifiable. From MS Excel to mechanical repair, every skill gets a badge.

### 🚜 Rural-First Design
Tailored UI/UX with regional greetings, accessibility-first design, and a focus on users new to digital platforms.

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/Aadi7171/Eklavya-AI.git
cd Eklavya-AI

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
